Getting started

What is still missing before Claude Desktop can talk to the proxy.

    API keys

    Written to .env in the project root. Existing keys are shown masked — leave a field empty to keep the current one.

    Text provider

    With more than one key configured the proxy follows the priority OpenCode Go → GLM → DeepSeek → Google AI Studio. Pin a provider here to override that order. Images go to Google either way — straight to it when it is the text backend, through OCR otherwise.

    Proxy port

    Changing the port does not require reissuing the certificates, but Claude Desktop has to point at the new URL — use Write configuration under Diagnostics after saving.

    Models by provider

    With discovery on, the proxy asks that provider for its model list at startup (and every 30 min) and publishes each model as a claude-… id — which is all Claude Desktop requires. With it off, only the static maps in proxy/server.js apply. Uncheck anything you do not want in the model picker; with everything checked no list is written and the whole catalog applies. Hover an id to rename it — the claude- prefix is required and stays fixed.
